# smrs-avatars

Photorealistic portrait images for the Synthetic Merchant Research Swarm personas.

**Every face here is fictional and AI-generated** (no real person is depicted). The images give each
synthetic merchant persona a consistent human identity when it posts research feedback to Slack
(Slack's per-message `icon_url` requires a publicly reachable HTTPS URL, which is the only reason
this repo is public). Filenames are `<persona-id>.png`.
